# Paper Safari - 웹 기반 보드게임 시뮬레이터

Paper Safari는 동물 이동 시뮬레이션 보드게임을 웹에서 즐길 수 있는 인터랙티브 플랫폼입니다.

## 🎮 게임 개요

Paper Safari는 플레이어가 각자의 동물들을 사바나에서 이동시켜 최고 점수를 얻는 게임입니다.
- **2-4명 플레이 지원**
- **실시간 턴 기반 게임플레이**
- **AI 플레이어 옵션**
- **게임 통계 및 리플레이 기능**

## 🏗️ 프로젝트 구조

```
paper-safari/
├── frontend/          # React 기반 웹 UI
├── backend/           # Node.js/Express 게임 서버
├── game-engine/       # 게임 로직 및 규칙
├── docs/              # 게임 규칙 및 문서
└── tests/             # 테스트 파일
```

## 🚀 시작하기

### 사전 요구사항
- Node.js 18+
- npm 또는 yarn

### 설치

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 테스트 실행
npm test
```
